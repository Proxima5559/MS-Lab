
# 🧪 MS-Lab
This is a simple test project built with React and Flask and basic pages.

This repository is just a small React+Flask test project for learning and checking how pages work.



## ❔ How to run
```bash
poetry install
poetry run flask run
```
## 🚪 Frontend
```bash
npm install
npm start
```
## 🗒️ Notes
Both the Flask backend and the React frontend must be running for the project to work.

If your Flask app uses a different entry file or app name, update the command accordingly.
